# ⚡ TaskFlow — Modern Flutter Todo App

A modern, attractive, and intuitive Task & Todo management application built with **Flutter 3** and compiled automatically using **GitHub Actions**.

---

## ✨ Features

- 🎨 **Modern Material 3 Design**: Sleek dark & light theme modes with vibrant gradients and card elevations.
- 📊 **Progress Dashboard**: Dynamic completion indicator with real-time motivational feedback.
- 🏷️ **Categories & Tags**: Work, Personal, Fitness, Study, Shopping, and Finance with distinct visual styling.
- 🚨 **Priority Levels**: Urgent, High, Medium, and Low with color-coded badges.
- 🔍 **Real-Time Search & Tabs**: Filter instantly by `All`, `Today`, `Upcoming`, or `Done`.
- 👆 **Gesture Support**: Swipe-to-delete with quick Undo snackbars, interactive checkboxes, and bottom sheet editing.
- ☁️ **Cloud CI/CD**: Built completely on GitHub Actions without requiring local Flutter or Android SDK installation!

---

## 🚀 Automated Builds via GitHub Actions

This repository is configured to automatically compile Android APKs on push using GitHub Actions runners.

### How to download the APK:
1. Navigate to the [Releases](../../releases) tab or [Actions](../../actions) tab in this repository.
2. Select the latest workflow run or release.
3. Download `TaskFlow-v1.0.0.apk` directly to your phone and install!
